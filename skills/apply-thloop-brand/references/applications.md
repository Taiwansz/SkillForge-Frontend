# ThLoop application rules

## Logo selection matrix

| Application | Mark | Treatment |
|---|---|---|
| Website navigation | Full wordmark; Twin Chamber on narrow mobile | Flat SVG |
| App icon / favicon | Twin Chamber | Flat, high-contrast |
| Social avatar | Twin Chamber | No surrounding graphic beyond platform mask |
| Hero / boot screen | Full wordmark | Off-white on black |
| Equipment badge | Full wordmark | Engraved/debossed, monochrome or tiny gold notch |
| Garment chest patch | Twin Chamber | Tonal rubber or embroidery |
| Garment back | Full wordmark | Off-white print/embroidery |
| Credential | Full wordmark | Chicane Cut may crop one edge |
| Technical document | Full wordmark | Small; Chicane Cut at page edge |
| Event wall | Full wordmark | Mounted letters or print |
| Seal / folio marker | Twin Chamber | Monochrome |

## Clear space and size

- Full wordmark clear space: at least one gold-notch width on all sides; prefer the height of an `o` counter.
- Twin Chamber clear space: at least one-quarter of the mark height.
- Minimum digital wordmark width: 160px. Below this, use Twin Chamber.
- Minimum print wordmark width: 32mm.
- Minimum Twin Chamber: 16px digital, 6mm print; use monochrome below 24px/9mm.

## Backgrounds

- Approved: Loop Black, Technical Paper, Chassis, calm photography with sufficient contrast.
- On complex photography, use a solid quiet zone; never add glow or drop shadow.
- Use monochrome marks when production cannot reproduce the gold notch reliably.

## Physical production

- Engraving/debossing: use monochrome vector; preserve counters and do not reduce stroke gaps below manufacturer tolerance.
- Embroidery: simplify only through the provided embroidery asset; do not redraw manually.
- Foil: gold foil may reproduce only the notch or a hairline divider, never the whole logo.
- Matte finishes are preferred to gloss.

## Mockups

- Apply the canonical logo as a placed asset with perspective and material mapping.
- Keep spelling and geometry exact.
- Use a single directional light and restrained composition.
- Prefer realistic objects connected to engineering work: equipment cases, specification folders, credentials, technical apparel, devices, signage.
- Avoid luxury props unrelated to the work.
