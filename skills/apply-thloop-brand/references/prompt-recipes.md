# ThLoop image and mockup prompt recipes

Use these recipes only when generating supporting imagery or mockups. Always provide the canonical logo asset as an edit/compositing reference when the tool supports it. Never ask an image model to invent or typeset the logo.

## Product mockup

```text
Create a photorealistic premium engineering mockup. Apply the supplied canonical ThLoop Continuous Core wordmark unchanged to [surface]. Use Loop Black #0A0A0A, Technical Paper #F0EDE6, Chassis #2A2A2A, Smoked Mirror #5C5C5C, and no more than 3% Chicane Gold #C8B560. Use matte powder coat, smoked titanium, uncoated technical paper, and one directional grazing light. Preserve the logo's exact geometry, spelling, aspect ratio, double-o chamber, return stroke, and small diagonal gold notch. No gradients, glow, neon, third-party logos, decorative luxury props, or generic technology imagery.
```

## Apparel

```text
Create a restrained technical apparel mockup on black fabric. Place the supplied Twin Chamber compact mark unchanged as a small tonal chest patch and the supplied Continuous Core wordmark unchanged on the back. Preserve the single gold notch as a tiny stitch detail. Use realistic embroidery/rubber texture, no model, no varsity or esports styling, no extra patches, no large gold areas.
```

## Event environment

```text
Create a minimalist black hackathon judging environment. Mount the supplied Continuous Core wordmark unchanged as warm off-white brushed-metal lettering on the main wall. Use Twin Chamber only on compact wayfinding and Chicane Cut only as a cropped wall/floor visual device. Matte black architecture, narrow white strip lights, no neon, sponsor clutter, people, or futuristic spaceship styling.
```

## Supporting textures

```text
Create a macro material study for the ThLoop identity: smoked titanium, matte black powder coat, carbon-fiber weave, warm uncoated technical paper, smoked acrylic. One directional grazing light, absolute black negative space, no logos, no text, no gold except one hairline registration cut.
```
