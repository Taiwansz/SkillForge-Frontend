# Prompt recipes

Use these recipes when generating supporting visuals. Always attach the canonical logo or icon when the tool supports image references. Generated artwork must not redraw or mutate the logo.

## Editorial hero background

> Create a wide editorial vector composition for TokLang using brushed silver, deep wine, and safety yellow. Show a broad curvilinear language stream compressing through one narrow yellow spine and emerging as a smaller structured ribbon. Mature developer-tool aesthetic, asymmetrical grid, generous copy-safe negative space, subtle print grain. No text, no logos, no blue, green, purple, robots, circuits, gears, pipes, or childish doodles.

## Dark technical illustration

> Create a dark TokLang technical illustration on near-black wine. Thin muted-silver input traces converge through a precise safety-yellow compression bar and become a short deep-wine token stream. Flat vector, controlled line weight, high contrast, large empty area for a headline, mature and energetic. No neon glow, 3D glass, terminal screenshot, or generic AI imagery.

## Social result card

> Design a bold TokLang result card with one oversized savings metric, a compact original-versus-compressed comparison, brushed-silver background, deep-wine typography, and one safety-yellow compression accent. Use a cropped curvilinear corner ribbon. Editorial, technical, readable at mobile size. Leave the logo area blank for the canonical asset.

## Pattern expansion

> Create a seamless vector pattern derived from curved compression streams and token nodes. Deep wine strokes on brushed silver with sparse safety-yellow gates. Geometric rhythm with round joins, no letters, no icons, no random blobs. Maintain 60% calm negative space.

## Review generated art

Reject art that:

- resembles factory engineering more than language technology;
- feels juvenile, toy-like, gamer-like, or cyberpunk;
- uses the yellow as a generic glow;
- invents another TK monogram;
- places decoration behind important copy;
- depicts savings without labeling them as illustrative.
