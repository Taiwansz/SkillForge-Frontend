# Voice and content

## Voice

TokLang sounds compact, technically credible, and slightly provocative. It proves value with examples instead of claiming magic.

### Write like this

- `Menos tokens. A mesma intenção.`
- `Comprima o prompt. Preserve o significado.`
- `Mapeamento reversível para fluxos com LLM.`
- `Veja o que entrou, o que foi mapeado e quanto saiu.`

### Avoid

- `Revolucione sua jornada com IA.`
- `A solução definitiva do futuro.`
- unexplained superlatives;
- anthropomorphizing the mapper;
- calling estimated savings exact.

## Product labels

Prefer concrete nouns and verbs:

- `Comprimir texto`
- `Expandir tokens`
- `Ver mapeamento`
- `Tokens de entrada`
- `Tokens de saída`
- `Economia estimada`
- `Dicionário ativo`

## Technical claims

Every claim about savings should state the tokenizer/model or methodology when known. Use ranges when results vary by text and model. Distinguish character reduction, token reduction, latency, and cost.

## Capitalization

- Brand: `TokLang`
- Product feature names: sentence case in Portuguese.
- API objects and literal tokens: monospace, preserving their exact case.

## Error messages

State what happened and what the user can do next. Example: `O texto ultrapassa o limite configurado. Reduza a entrada ou ajuste o limite da API.`
