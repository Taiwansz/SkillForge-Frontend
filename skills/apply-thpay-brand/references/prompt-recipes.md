# THP / ThPay image and mockup prompt recipes

Use image generation for supporting photography, campaign art or contextual mockups. Use canonical SVG assets for the actual logo whenever compositing/editing is supported. Never ask an image model to invent the THP symbol or typeset `ThPay` as the production logo.

## Brand board

`Create a structured THP / ThPay identity board with a warm ivory canvas, Ink Navy typography, rounded modular blocks in Cobalt, Solar, Mint, Blush and Coral, generous spacing, friendly professional tone, strong grid, no fintech clichés, no dark cyber styling. Reserve clear zones for the canonical logo assets to be composited afterwards.`

## People campaign

`Contemporary Brazilian workplace portrait, competent relaxed professional, natural daylight, candid expression, warm neutral environment, subtle modular color fields derived from THP Connection Blocks, optimistic but not stock-photo exaggerated, premium HR technology campaign.`

## Product illustration

`Editorial vector-style scene about payroll and people operations using rounded connected modules, simple human figures, Ink Navy outlines, Warm Ivory background, Cobalt/Mint/Blush/Coral/Solar accents, clear hierarchy, friendly and precise, no currency signs, no shields, no glowing technology motifs.`

## Presentation cover

`Clean editorial technology cover with one large human-centered statement, warm ivory field, Ink Navy typography, oversized cropped Connection Blocks along one edge, restrained bright color, large negative space for the canonical THP / ThPay lockup.`

## Avoid in prompts

Do not request: neon, cyberpunk, holographic dashboards, generic bank cards, wallets, dollar/real symbols, security shields, fake code, crypto imagery, dark blue gradient SaaS backgrounds, random 3D blobs or glassmorphism.
